# 交通与周边

::: warning 线路与店铺信息请以实际为准
公交线路、店铺营业情况变化很快。这篇给的是**方法**：怎么查、怎么选、注意什么。具体线路请用地图 App 实时查询。
:::

## 上下学怎么走

### 走读生

优先顺序建议：

1. **步行 / 骑行（距离 3 公里内）** —— 时间可控，不受堵车影响
2. **公交** —— 便宜，但早晚高峰拥挤，且可能不准点
3. **家长接送** —— 舒适，但校门口高峰时段极堵
4. **拼车** —— 同小区同学一起，成本和效率折中

### 骑行要注意

- 头盔不是可选项
- 提前探一次路线，找车流少的小路
- 雨天不骑，十堰雨天路面湿滑，山地地形多
- 车要停在指定区域并上锁

## 家长接送的实用建议

校门口在放学时段是最堵的地方。几个能省时间的做法：

- **约定固定接送点**，离校门 200–300 米，避开拥堵核心区
- **提前 10 分钟到**，而不是准点到，准点往往要排很久
- **加一个同学家长的群**，轮流接送能明显减轻负担
- 找不到人时，**约定一个显眼的地标**（某个店门口），比说「校门口」有效

## 十堰城区出行的几个常识

十堰是山地城市，道路依山而建，这带来两个特点：

- **直线距离近 ≠ 实际路程近**。看着隔一座山，可能要绕很大一圈
- **雨天和雾天通勤时间会明显延长**，出门要留余量

## 周边值得知道的店铺类型

不写具体店名（会变，也容易变成广告），按类型说：

| 类型 | 用途 | 注意 |
| --- | --- | --- |
| 文具店 | 笔、本子、考试用品 | 开学季涨价，提前备 |
| 打印店 | 作业、资料、证件复印 | 学校周边通常比市区便宜 |
| 书店 | 教辅、课外书 | 教辅别乱买，等老师指定 |
| 药店 | 常用药 | 记住 24 小时药店位置 |
| 超市 | 日用品、零食 | 校内小卖部通常更贵 |
| 理发店 | —— | 周末排队，错峰去 |
| 眼镜店 | 配镜、修镜 | 高中生近视加深快，半年查一次 |

## 放假回家的长途出行

- **火车票提前买**，节假日前 15 天开售，热门线路很快没了
- **学生票**：凭学生证可享受优惠，注意每年有次数限制和区间限制
- **汽车站**：提前确认发车时间，山区线路班次不密
- **别坐黑车**，尤其是夜里和拼车群里来路不明的车

## 安全底线

::: danger 这几条不要省
1. **不坐无营运资质的车**，包括群里的「顺风车」私家车
2. **夜间不单独走偏僻路段**，宁可绕远走大路
3. **手机保持有电**，随身带充电宝
4. **把行程告诉家人**，尤其是临时改变路线时
5. **遇到尾随或骚扰，直接进店、进人多的地方并打电话**，不要硬扛
:::
