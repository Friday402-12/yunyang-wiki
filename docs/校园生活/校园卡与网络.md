# 校园卡与网络

## 校园卡：丢了先做这一步

::: danger 第一件事永远是挂失
发现卡丢了，**立刻挂失**，不要先找。挂失渠道通常是卡务窗口、自助机或线上小程序。找到后再解挂，比被人刷光余额再补办好得多。
:::

### 常见问题

| 问题 | 怎么办 |
| --- | --- |
| 卡丢了 | 先挂失 → 找 → 找不到就补办（带照片、可能要工本费） |
| 余额不足 | 线上充值（微信/支付宝/学校 App）或自助机 |
| 卡消磁 / 刷不上 | 卡务窗口处理，别自己弯折 |
| 毕业 / 转学 | 办理退卡退余额，别直接扔掉 |

### 用卡习惯

- **卡背面写上班级和姓名**，捡到的人能还给你
- 不要和手机长期贴放，部分卡片容易被消磁
- 一次别充太多，丢了损失小
- 记住卡号后四位，挂失时报得出来

## 学校网络

不同学校的网络策略差异很大，先搞清楚三件事：

1. **有没有校园 Wi-Fi**？覆盖哪些区域？
2. **是否需要账号认证**？账号从哪来？
3. **有没有使用时间限制**？

### 如果学校限制网络

这是常态，不是针对你。可以做的：

- 提前把要用的资料**下载到本地**
- 用离线词典、离线题库
- 需要联网查资料，集中到允许的时段做，别零散地试

## 手机：怎么用才不被没收

学校对手机的管理通常比较严格，具体规定看《学生手册》。这里不是说怎么钻空子，而是几条**能让手机真正帮到你**的建议：

- **别在上课时间碰手机**，被收走一次，可能影响一整个学期
- **把手机当工具而不是消遣**：查词、拍板书、定闹钟、记录待办
- **卸载短视频类 App**，或者至少关掉推送。高中三年最贵的东西是注意力
- **睡前把手机放到够不着的地方**，这一条比任何时间管理方法都有效

::: tip 一个真实有效的做法
如果你控制不住自己，就主动把手机交给家长或班主任保管，只在周末取回。听起来极端，但很多成绩提升明显的同学都干过这件事。
:::

## 电脑与学习工具

- 学校机房通常可用于查资料、做课件
- **U 盘**建议备一个，打印资料、拷贝课件常用
- 如果需要长期保存笔记，建议用在线文档（能自动保存、多设备同步），但注意学校网络是否允许

## 电子设备与视力

- 高中生近视加深很快，**每半年查一次视力**
- 屏幕亮度别太高，夜间开护眼模式
- 连续用眼 40 分钟，看远处 20 秒
- 眼镜度数不合适会加重疲劳，直接影响学习效率
