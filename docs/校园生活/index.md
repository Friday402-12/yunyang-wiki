# 校园生活

高中三年，真正占据你时间的不是考试，是每天重复的那些小事：几点起、吃什么、几点睡、衣服在哪晾。

这些事没人正式教过，但它们的质量直接决定你上课能不能听进去。

::: info 为什么这一栏是空的
之前的版本写的是「错峰吃饭」「荤素搭配」这类通用建议——**放在任何一所学校都成立，也就等于什么都没说。**

现在这些内容已经撤下，等真正在郧中生活的人，把具体的东西补上来：哪个食堂几楼、几点人最少、熄灯前多久要洗漱完。
:::
