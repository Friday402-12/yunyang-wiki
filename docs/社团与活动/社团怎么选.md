# 社团怎么选

::: warning 这份名单需要你补充
各校社团每年有增减，具体名单请以当年招新公告为准。**如果你是在校生，欢迎把你们社团的真实情况补充进来**——这比任何通用建议都有用。
:::

## 常见社团类型

### 学术类

- 文学社、辩论社、英语角
- 数学 / 物理 / 化学 / 生物兴趣小组
- 模拟联合国、模拟政协

**适合**：想在某个学科深入、喜欢思考和表达的人。
**注意**：部分学术社团实质是「竞赛培训班」，报名前问清楚。

### 文艺类

- 合唱团、乐队、舞蹈社
- 话剧社、相声社
- 书法、绘画、摄影

**适合**：有特长、想在高压学习之外保留一块精神空间的人。
**注意**：排练通常占用周末或晚间，演出季更密集。

### 体育类

- 篮球、足球、羽毛球、乒乓球
- 田径、武术、健美操

**适合**：想保持体能、喜欢团队运动的人。
**注意**：这是最不占学习时间的社团类型，强烈推荐至少参加一项。

### 实践与公益类

- 志愿服务队
- 环保社、心理社
- 校园媒体（广播站、校刊、摄影组）

**适合**：想接触真实世界、积累综合素质评价材料的人。
**注意**：志愿服务时长在部分升学通道（综合评价）中有用，但别为了时长做形式主义。

### 技术与创意类

- 信息学 / 编程社
- 机器人社
- 动漫社、手工社

## 招新时该问的五个问题

招新宣讲都很好听。用这五个问题穿透包装：

1. **一周大概占多少时间？** 具体到小时，不要接受「不多」这种回答
2. **有没有固定的指导老师？** 没有老师的社团，很容易半途而废
3. **过去一年实际办成了什么事？** 看成果，不看规划
4. **高三还在的学长学姐有几个？** 这个数字能反映社团的真实强度
5. **退出机制是什么？** 能不能中途退，退了会不会有影响

::: tip 第 1 个问题最关键
一个占你每周 8 小时的社团，和一个占 1 小时的社团，是完全不同的两个决定。**先把时间问清楚，其他都好说。**
:::

## 怎么判断值不值得留

待一个学期后，用这三个标准检验：

- **你有没有学到具体的东西**（一项技能、一种思维方式、一群能聊的人）
- **它有没有影响你的睡眠和成绩**（如果连续两次考试明显下滑，就该重新评估）
- **你是不是每次活动前都觉得不想去**（如果是，那就是答案）

## 关于「社团经历」和升学

诚实地说：

- **对裸分高考几乎无影响**
- 对**综合评价**招生、部分高校的面试可能有加分作用，但远不如成绩重要
- 对**强基计划**基本无影响
- 真正有用的是你**从中获得的能力**，而不是「参加过」这三个字

::: danger 别为了简历做社团
如果你参加社团的唯一目的是「写进材料」，那大概率既拿不到成果，也浪费了时间。招生老师见过的包装，比你想的多得多。
:::

## 如果学校社团不能满足你

- **自己发起**。多数学校允许学生申请成立新社团，需要指导老师和一定人数
- **参加校外活动**。竞赛、科创比赛、志愿服务、线上学习社群
- **自己组队**。三五个同学一起做个项目，比加入一个松散社团更有价值
