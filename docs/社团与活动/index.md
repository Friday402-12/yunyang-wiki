# 社团与活动

高中社团常被两种极端评价：一种说「浪费时间」，一种说「青春必备」。

实际情况是：**选对了，它是你三年里最重要的非学业成长；选错了，它确实只是消耗。**

::: info 为什么这一栏是空的
「选社团的五个原则」这种内容你已经看过很多遍了。真正缺的是名单：**学校到底有哪些社团、谁在带、招新在哪天、一年大概占多少时间。** 这些没人整理过。
:::
