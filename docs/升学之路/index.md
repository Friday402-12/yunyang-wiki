# 升学之路

高考这件事，一半在考场，一半在考场之外。

同样是 600 分，有人去了理想的学校，有人调剂到了完全不了解的专业——差别往往不在分数，而在**信息**。

::: info 为什么这一栏是空的
「平行志愿按顺序检索、投中即停」这种规则，查官方文件就能得到，抄一遍没有价值。

真正缺的是**本校的数据和经验**：这几年各分数段大概去了哪里、强基和专项在我们学校怎么报名、出分后那几天该找谁。等这些拿到手，再写。
:::
