# 升学之路

高考这件事，一半在考场，一半在考场之外。

同样是 600 分，有人去了理想的学校，有人调剂到了完全不了解的专业——差别往往不在分数，而在**信息**。

这一栏的目标，是把那些看起来复杂的招生规则，翻译成你能直接用的判断。

<ArticleList only="升学之路" />

::: warning 政策随时会变
招生政策每年都在调整。本栏内容用于帮你建立认知框架，**所有具体规定必须以教育部、湖北省教育考试院和目标高校当年发布的正式文件为准**。
:::
