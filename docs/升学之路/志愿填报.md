# 志愿填报

出分后那一周，是很多人一生中最密集做决策的七天。这篇给你一个可以直接照着走的流程。

## 出分前：准备工作（最重要）

::: tip 真正拉开差距的地方在这里
出分后有 5–7 天，但你要同时应付亲戚的意见、同学的讨论、招生老师的电话。**能在出分前做完的事，绝不留到出分后。**
:::

### 高三寒假：缩小范围

- 用**位次**（不是分数）对照去年的录取数据，圈出 30–50 所可能的学校
- 每所学校记下：所在城市、优势专业、往年最低位次、学费
- 排除掉你绝对不会去的（太远、太冷、学费太高）

### 高三下：研究专业

- 每个目标学校，选 2–3 个专业深入了解
- 重点看：**这个专业学什么课、毕业干什么、有没有转专业机会**
- 别只看名字。「信息与计算科学」是数学专业，不是计算机

### 出分后第一天：定位

拿到分数和**全省位次**，做三件事：

1. 查一分一段表，确认位次
2. 用位次去对去年的录取数据（不看分数，只看位次！）
3. 列出「冲、稳、保」三档学校

## 冲稳保怎么排

| 档位 | 定位 | 建议比例 | 说明 |
| --- | --- | --- | --- |
| 冲 | 位次比你高 5%–15% | 20%–30% | 有希望但不保险，要能接受最坏结果 |
| 稳 | 位次和你接近（±5%） | 40%–50% | 主力区，重点研究 |
| 保 | 位次比你低 15% 以上 | 20%–30% | 兜底，必须确保能上 |

### 三条排序原则

1. **最想去的放最前面**，不要「按分数从高到低」机械排。平行志愿是顺序检索，前面放保底校等于浪费机会
2. **同一层次内部，按专业满意度排**，不是按学校名气排
3. **保底志愿必须真的保得住**。最后 2–3 个志愿，选比你位次低很多的学校

::: danger 最常见的致命错误
把「保底校」放在中间，后面填了几个「冲」的学校。结果被保底校录走，后面全部作废。
:::

## 专业怎么选

### 三个要问自己的问题

1. **我愿意学四年吗？** 不是「好不好就业」，是「我能不能坚持」
2. **我知道它学什么课吗？** 去学校官网查培养方案，看课程表
3. **如果转不了专业，我能接受吗？** 很多学校转专业有名额和成绩限制

### 专业选择的现实考虑

- **热门 ≠ 适合**。计算机很热，但学不下去的人非常多
- **冷门 ≠ 没前途**。基础学科（数学、物理）读研后选择面很广
- **看行业趋势，但别赌**。四年前的「热门」现在可能已经饱和
- **地域很重要**。实习机会、就业半径、生活习惯都和城市强相关

### 关于「服从调剂」

| 情况 | 建议 |
| --- | --- |
| 分数在该校专业组里有优势 | 可以不服从，但要确认所填专业都够 |
| 分数刚够投档线 | **强烈建议服从**，否则大概率退档 |
| 该组里有你完全不能接受的专业 | 换一个专业组，别赌 |

## 出分后那一周的行动清单

**Day 1**
- 查位次，做一分一段对照
- 列出初步的冲稳保名单（各 10 所）

**Day 2**
- 逐所查：招生章程（有没有单科要求、身体限制）、专业组设置、往年位次
- 打电话问招生办：转专业政策、住宿条件、奖助学金

**Day 3**
- 排除法：删掉不去的城市、不学的专业
- 名单缩到 20 所左右

**Day 4**
- 排序：把最想去的往前放
- 检查：保底够不够稳？有没有漏掉选科要求？

**Day 5**
- 找 2–3 个人帮你看一遍：班主任、上过大学的亲戚、在读的学长学姐
- **不要找太多人**，意见越多越乱

**Day 6–7**
- 网上填报，**填完立刻截图保存**
- 提交后再次登录确认状态
- 保存好密码，注意截止时间（通常是下午，不是午夜）

## 几个容易被忽略的细节

- **招生章程比招生简章重要**。章程有法律效力，写了单科要求就是硬要求
- **看清专业组内的专业**。服从调剂是在「组内」调剂，不是全校
- **中外合作办学学费高**，看清楚金额再报
- **提前批不服从调剂不影响本科批**，可以大胆冲
- **关注征集志愿**，部分学校补录时分会降
