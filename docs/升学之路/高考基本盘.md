# 高考基本盘

::: warning 请以官方文件为准
本文梳理的是**逻辑框架**，具体的分值、批次名称、时间安排在每年文件中可能微调。请以湖北省教育考试院当年发布的招生实施办法为准。
:::

## 一、考什么

湖北实行新高考，模式为 **3+1+2**：

| 类别 | 科目 | 计分方式 |
| --- | --- | --- |
| 3（必考） | 语文、数学、外语 | 原始分，各 150 分 |
| 1（首选） | 物理 或 历史，二选一 | 原始分，100 分 |
| 2（再选） | 从化学、生物、政治、地理中选两门 | **赋分**，各 100 分 |

总分 **750 分**。

### 什么是「赋分」

再选科目不是按你考了多少分算，而是按**你在全省选这科的人里排第几**换算成分数。

这意味着：

- 卷子难，大家分都低，但赋分后不会集体崩盘
- 你选了一科「牛人扎堆」的科目，赋分会吃亏
- 相反，选了一科整体水平偏弱的，赋分可能占便宜

这就是[选科](/学习指南/选科)不能只看「哪科容易考高分」的原因。

## 二、怎么录

录取的基本单位是「**院校专业组**」。一个高校可以设多个专业组，每个组对应一套选科要求。

### 投档的基本逻辑

1. 按考生总分从高到低排队
2. 轮到你时，按你填的志愿顺序依次检索
3. 找到第一个「还有名额且你符合选科要求」的专业组，投档
4. 投进去之后，再看你填的专业志愿，决定录取到哪个专业

::: tip 一个关键理解
**平行志愿不是「同时投几个」，而是「按顺序检索，投中即停」**。所以志愿顺序极其重要——放在前面的，应该是你真正想去的。
:::

### 退档的风险

投档成功不等于录取。以下情况可能被退档：

- 不服从专业调剂，且分数不够所填专业
- 身体条件不符合专业要求（如色盲不能报某些专业）
- 单科成绩不达要求（部分专业有英语或数学单科线）

**「不服从调剂」是退档最常见的原因。** 是否勾选，需要权衡：勾了可能被调到不喜欢的专业，不勾可能直接掉到下一批次。

## 三、批次与特殊类型

大致顺序（具体名称以当年文件为准）：

1. **提前批**（军校、公安、公费师范、部分艺术类）
2. **本科批**（主体，包含绝大多数本科院校）
3. **专科批**

此外还有强基计划、综合评价、专项计划等特殊通道，见[竞赛与强基](/学习指南/竞赛与强基)。

## 四、几个必须知道的时间节点

| 时间 | 事项 |
| --- | --- |
| 高三上（10–12 月） | 高考报名、专项计划资格申报、招飞报名 |
| 高三下（3–4 月） | 强基计划报名、综合评价报名 |
| 6 月 7–9 日 | 高考 |
| 6 月下旬 | 出分、公布分数线 |
| 6 月底–7 月初 | 志愿填报（时间很紧，提前准备） |
| 7 月 | 录取、征集志愿 |

::: danger 志愿填报只有几天
出分到填志愿通常只有 5–7 天。**不要等出分才开始研究**。高三寒假就应该把目标院校范围缩小到 20 所以内。
:::

## 五、现在（高一高二）能做什么

1. **把成绩稳住**。所有策略的前提都是有分可报
2. **搞清楚自己的选科能报什么专业**（见[选科怎么选](/学习指南/选科)）
3. **了解专项计划资格**。农村户籍的同学务必问班主任
4. **记录自己的兴趣倾向**。不用现在决定，但要开始观察
5. **别过早焦虑**。高一就天天想着填志愿，反而会打乱节奏
