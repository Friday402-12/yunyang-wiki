# 常见部门与联系方式

::: warning 电话与办公地点请核实后使用
具体电话号码会变动，本站不公开未经确认的号码，避免误导。**正确做法：入学时从《学生手册》或班级群里保存一份官方联系方式，并定期和同学互相校对**。下面告诉你的是「什么事该找谁」。
:::

## 先问谁：一张对照表

| 你要办的事 | 该找谁 | 备注 |
| --- | --- | --- |
| 请假（1 天内） | 班主任 | 超过一定天数需报政教处 |
| 请假（多天 / 病假） | 班主任 → 政教处 | 病假通常要医院证明 |
| 成绩查询、成绩更正 | 教务处 / 任课老师 | 先找任课老师核对 |
| 学籍证明、在读证明 | 教务处 | 出国、贷款、比赛报名常需 |
| 转学、休学、复学 | 教务处 | 材料多，提前问清清单 |
| 补办学生证、校牌 | 政教处 / 教务处 | 需照片 |
| 补办校园卡 / 饭卡 | 卡务中心或指定窗口 | 挂失要第一时间做 |
| 团组织关系转接 | 团委 | 线上「智慧团建」+ 线下确认 |
| 奖学金、助学金、免学费 | 政教处 / 资助中心 | 需家庭情况材料 |
| 违纪处理、申诉 | 政教处 | 有正式流程，别私下解决 |
| 宿舍维修、换宿舍 | 宿管老师 → 政教处 | 先找宿管登记 |
| 身体不舒服 | 医务室 / 校医 | 夜间找值班老师 |
| 情绪困扰、压力大 | 心理咨询室 | 保密，不记入档案 |
| 缴费、退费 | 财务室 | 只走对公渠道 |
| 社团注册、活动申请 | 团委 | 需指导老师签字 |
| 图书馆借书、办证 | 图书馆 | 逾期有滞纳金 |

## 三条沟通原则

### 1. 找对人，比说对话更重要

同一个问题，找错部门会被来回推。判断方法很简单：

- **和「学」有关** → 教务处
- **和「人 / 纪律 / 评优」有关** → 政教处
- **和「团 / 社团 / 志愿」有关** → 团委
- **和「钱」有关** → 财务室
- **和「住」有关** → 宿管 → 政教处

### 2. 请假不要口头

无论多急，走正式流程。口头请假 + 事后补批，是最容易变成「旷课」的组合。留痕（书面假条、系统记录、聊天截图）保护的是你自己。

### 3. 不要绕过班主任

学生和学校之间，班主任是第一接口人。直接找校长或越级投诉，通常会让事情更难办。真有班主任解决不了的问题，家长出面沟通比学生自己硬扛有效得多。

## 家长需要知道的几个窗口

- **家长会** —— 通常每学期 1–2 次，是了解孩子真实状态最好的机会
- **班主任电话** —— 建议家长主动存，别等出事才找
- **缴费通知** —— 只认学校正式通知渠道，任何「老师」私聊要钱都要先电话核实

::: danger 关于诈骗
每年都有家长收到冒充班主任的收费消息。**凡是要求转账到个人微信、支付宝、银行卡的，100% 是诈骗**。学校收费一律走对公账户或官方缴费平台。
:::

## 建议做的一件事

开学第一周，在手机里建一个备忘录，标题叫「郧中联系方式」，把以下内容抄进去：

- 班主任电话
- 宿管值班室位置和电话
- 医务室位置
- 教务处、政教处、团委所在楼层
- 一两个高年级学长的联系方式

然后**每学期更新一次**。
