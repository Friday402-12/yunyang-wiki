# 校园速览

::: warning 本文需要核实
校园布局会随改扩建变化。这篇给的是「按功能分区理解校园」的方法，具体楼栋名称与位置请以入学时的实际校园为准，欢迎同学补充修订。
:::

## 先建立一张心理地图

新生迷路，通常不是因为校园大，而是因为**不知道该按什么维度记**。建议按「一天的行动路线」来记，比按建筑编号记有效得多：

```
宿舍 → 食堂 → 教学楼 → 操场 → 返回
```

把这条线走通，再往外扩展，就不容易乱。

## 按功能分区的六个地方

### 1. 教学区

上课的主战场。要记住的不只是「我的教室在哪」，还有：

- 本班教室
- 实验室（物理、化学、生物通常在不同楼层或不同楼）
- 计算机房
- 阶梯教室 / 报告厅（集会、讲座、公开课在这里）
- 教师办公室（找老师问问题、交作业要去）

**实用建议**：开学第一周，把每科老师办公室的位置记下来，写在课本扉页上。以后找老师不用每次问人。

### 2. 生活区

- **食堂** —— 记清楚有几层、各层供应什么、哪个时段最挤
- **宿舍** —— 记清本栋的熄灯时间、门禁时间、宿管值班室位置
- **开水房 / 直饮水点** —— 冬天这是刚需
- **洗衣房** —— 如果学校提供
- **浴室** —— 记清开放时段，错峰能省不少时间

详见[食堂](/校园生活/食堂)、[宿舍](/校园生活/宿舍)。

### 3. 运动区

- 田径场（早操、体育课、运动会）
- 篮球场、排球场、羽毛球场
- 体育馆（雨天的体育课在这里）
- 器材室（借器材要押学生证）

### 4. 行政与办事区

这一块新生最陌生，但迟早要用：

- **教务处** —— 学籍、成绩、转学、证明
- **政教处 / 德育处** —— 纪律、评优、处分
- **团委** —— 团组织关系、社团、志愿服务时长
- **财务室** —— 缴费、退费
- **医务室 / 校医室** —— 记住它在哪，以及晚上谁能找到
- **心理咨询室** —— 很多同学到高三才知道有这个地方，其实高一就可以去

### 5. 学习资源区

- **图书馆** —— 借阅规则、开放时间、自习座位
- **阅览室** —— 报刊、期刊
- **自习室** —— 周末和假期开放情况要单独确认

### 6. 出入口与周边

- 正门、侧门分别什么时间开
- 家长接送在哪等
- 最近的公交站、文具店、药店、打印店

## 两小时逛校路线

按这个顺序走，一趟能覆盖 90% 的日常场景：

1. 从正门进，看门卫室和访客登记处
2. 直走找**公告栏**（分班、通知、活动都贴这儿）
3. 找**教学楼**，进自己班级，认楼层和楼梯位置
4. 出教学楼找**教师办公室**
5. 走到**食堂**，看窗口和价格牌
6. 走到**宿舍**，记门禁时间和宿管室
7. 绕到**操场**，看跑道和器械区
8. 最后找**医务室**和**行政楼**

## 记不住的三个笨办法

- **拍照存相册**，建一个「校园」相簿，把各处的指示牌拍下来
- **在纸上画一遍**，手画一次比看十次地图记得牢
- **带室友一起走**，边走边讲，讲一遍等于复习一遍
