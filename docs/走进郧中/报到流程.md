# 新生报到流程

::: warning 本文需要核实
每年的报到安排都会调整（时间、地点、缴费方式都可能变）。下面给的是**常规流程框架**，用来帮你提前心里有数。**具体要求请以录取通知书内附的《新生报到须知》和班主任通知为准。**
:::

## 报到前一周要做的事

按重要性排序，而不是按紧急程度：

1. **确认录取通知书的全部附件** —— 通常包含报到须知、收费项目说明、资助政策告知书、住宿申请等。逐页看一遍，别只看第一页。
2. **办好身份证** —— 没有身份证会卡住学籍注册、银行卡、手机卡等一连串事项。还没办的，现在就去办，别等。
3. **拍证件照** —— 一寸、二寸，红底蓝底各备一版电子稿。开学后学生证、社团、竞赛报名都会用到，临时去拍又贵又排队。
4. **准备团组织关系转接材料** —— 团员需要转接组织关系，通常在「智慧团建」系统线上办理，问清楚初中团委老师。
5. **确认住宿还是走读** —— 这个决定影响你要带多少东西，以及要不要买床上用品。
6. **准备一张本人名下的银行卡** —— 用于缴费和各类退费。

## 报到当天的常规顺序

不同年份会调整，但逻辑基本一致：

1. **校门口查验** —— 出示录取通知书、身份证，领取报到流程单或指引。
2. **找到自己的班级** —— 公告栏或线上会公布分班名单。先在名单上找到自己的名字，再去对应班级的报到点。
3. **班主任处登记** —— 交材料、填表、领材料（学生手册、校服单据、宿舍钥匙条等）。这一步排队最长，材料最好用透明文件袋一次装齐。
4. **缴费** —— 现在多数通过线上或银行代扣，现场缴费的情况越来越少。**任何要求转账到个人账户的，一律先问班主任核实。**
5. **领校服、床上用品** —— 通常有专门发放点，注意当场清点尺码和件数。
6. **进宿舍安顿** —— 找床位、铺床、认识室友。宿舍号一般在班主任处或宿舍楼下公告栏。
7. **班会** —— 通常是报到当天晚上或第二天，班主任讲纪律、作息、注意事项。**这次班会的每一句话都重要，别缺席。**

## 行李清单

### 必带

- 录取通知书、身份证及复印件若干
- 证件照（一寸、二寸各一版）
- 团组织关系材料
- 缴费凭证 / 银行卡
- 换洗衣物、洗漱用品、拖鞋
- 常用药（感冒药、创可贴、肠胃药）

### 建议带

- **插线板**（宿舍插座通常不够用，这是最高频的后悔项）
- 台灯（部分宿舍熄灯后需要）
- 衣架、洗衣液、晾衣夹
- 水杯、饭盒（看学校要求）
- 雨伞、防晒
- 小锁（储物柜用）

### 别带

- 大功率电器（吹风机、电热壶、电煮锅）—— 多数学校明令禁止，且宿舍电路带不动
- 大量教辅书 —— 学校会统一订，先别买重了
- 贵重物品和大量现金

## 几个年年有人踩的坑

::: danger 这几条请认真看
1. **不要相信任何「帮你搞定分班」「内部名额」的说法。** 分班是学校行为，没有个人能操作的空间，这类话术全部是诈骗。
2. **群里的「班主任」不一定真是班主任。** 加群后先通过学校官方渠道核实群号和老师身份，尤其是涉及缴费时。
3. **床上用品先别急着自己买。** 部分学校统一采购并要求统一款式，先确认再买，否则退不掉。
4. **手机卡、宽带不要在校门口随便办。** 套餐水深，先问学长学姐和家里人。
:::

## 报到之后的三天

- 熟悉从宿舍到教室的路线，算好走路时间，别第一天就迟到
- 记住班主任和宿管老师的联系方式
- 把校园卡、水卡等办好并充一点钱
- 参加新生教育，其中**纪律与安全部分**要听仔细，很多处分都源于「不知道有这个规定」
