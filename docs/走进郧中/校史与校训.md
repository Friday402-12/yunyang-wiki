# 校史与校训

知道自己在哪读书，是件挺重要的事。郧中这所学校的年头，比大部分同学想象的要长得多。

## 一句话版本

十堰市郧阳中学的前身是**郧山书院**，始建于明嘉靖二十六年（**1547 年**）。1902 年改办为「郧阳府中学堂」，开启鄂西北现代教育的先河。此后几经更名与迁址，1994 年地市合并后定名为「湖北省十堰市郧阳中学」。

## 时间线

| 年份 | 事件 |
| --- | --- |
| 1547 | 郧阳巡抚于湛命知府徐桂在府治城下建**郧山书院** |
| 1902 | 清廷颁《钦定学堂章程》，书院改为**郧阳府中学堂** |
| 1912 | 改称**郧山中学** |
| 1942 | 与省立联合中学均县分校合并，成立**湖北省立第八高级中学** |
| 1956 | 因襄阳、郧阳合并，改名为**湖北省郧县第一中学** |
| 1994 | 十堰市与郧阳地区合并，定名**十堰市郧阳中学** |
| 1999 | 学校由郧县城关迁至十堰城区 |
| 2006 | 通过评估，获评**湖北省示范高中** |

## 校训：明德博学，进而不已

八个字，两句话：

- **明德博学** —— 先把人做好，再把学问做大。语出《大学》「大学之道，在明明德」。
- **进而不已** —— 一直往前走，不停。「已」是停止的意思，不是「已经」。

合起来的意思是：德行为先、学问为基，而且要持续地精进，不能停在某一个阶段。

::: tip 一个实用的提醒
「进而不已」这四个字在高三特别管用。它没说「进而得第一」，只说「不停」。名次起落是常态，停下来才是问题。
:::

## 学校精神与办学理念

- 郧中精神：**责任、奉献、超越**
- 办学使命：**对学生负责，为民族担当**

这些词在集会和墙报上出现频率很高，容易听成空话。但如果你在校史馆看过那些老照片——抗战时期西迁办学、解放后重建——会发现这些词是有具体所指的。

## 知名校友

校史资料中常被提及的有：马克思主义哲学家、教育家杨献珍，鄂西北早期共产党员何世昌烈士，炮兵专家史丁文，「两弹一星」功臣张树清，作家梅洁等。
