# 走进郧中

「走进郧中，走向成功」是学校常挂在嘴边的一句话。但这所学校从哪来、为什么叫这个名字、校训八个字到底什么意思——大多数同学读了三年也没弄清楚。

这一栏目前**只保留经过核对的校史与校训**。报到流程、部门联系方式这类更实用的条目，正在等真实信息——**宁可空着，也不放一份可能过期的攻略。**

::: tip 关于内容可靠性
本栏内容由学生整理，**不是学校官方文件**。涉及报到、缴费、分班、学籍这类事务，一律以学校通知和班主任要求为准。我们的价值是帮你提前知道「大致会经历什么」，而不是替代通知。
:::
