# 走进郧中

「走进郧中，走向成功」是学校常挂在嘴边的一句话。但真到了报到那天，你会发现真正让人手足无措的不是理想，而是「宿舍在哪栋楼」「找谁开证明」「家长的车能停哪儿」。

这一栏解决的就是这些具体问题。

::: tip 先看这一条
本栏内容由学生整理，**不是学校官方文件**。涉及报到、缴费、分班、学籍这类事务，一律以学校通知和班主任要求为准。我们的价值是帮你提前知道「大致会经历什么」，而不是替代通知。
:::
