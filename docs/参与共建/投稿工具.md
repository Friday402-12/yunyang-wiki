## 拿到文件之后怎么办

1. **重命名**成工具提示的文件名（不改也行）
2. 把 `.md` 文件和图片（如果有）**一起打包**
3. 发给 Wiki 小组：微信群 / QQ 群 / 邮箱，任一渠道都行
4. 等一两天，你的文章就会出现在网站上

## 不想下载文件？

直接在表单里写完，点「复制全文」，然后粘贴到微信或 QQ 发给我们就行。我们会帮你存成文件。

## 想自己动手改网站？

如果你会一点技术，可以：

1. 在 GitHub 上找到本站仓库
2. 页面底部点「发现错误？帮我们改一改」
3. 直接在线编辑，提交后等审核

## 关于你的内容

- **署名**：默认显示你在表单里填的名字，可以写「某同学」或留空（显示为「匿名同学」）
- **修改**：上线后你随时可以要求修改或删除
- **版权**：内容按 CC BY-NC-SA 4.0 共享，允许转载但需署名、不得商用

::: tip 写得不好也没关系
我们可以帮你改。**最怕的是你觉得「我写的太简单了，不值得发」。** 一句「三食堂二楼靠窗的位置下午有太阳，别坐」对别人就是有用的信息。
:::
