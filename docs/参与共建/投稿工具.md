## 写完之后怎么交

### 方式一：直接提交到 GitHub（最推荐，不用加任何人）

**不需要会 Git，也不需要仓库权限。** 点下面的链接，把上面生成的文字粘进去，提交即可：

[打开投稿 / 纠错表单 →](https://github.com/friday402-12/yunyang-wiki/issues/new?template=content-issue.yml)

提交后会生成一个 Issue，Wiki 小组能看到。想补细节、催进度，就在同一个 Issue 里回复。

### 方式二：复制全文，粘给我们

点上面的「复制全文」，粘贴到微信或 QQ 发给 Wiki 小组的任何一个人即可，我们会帮你存成文件。

### 方式三：下载文件再转发

点「下载 .md 文件」，把文件和图片（如果有）一起打包发过来。内容长、格式复杂时用这个。

::: tip 找不到人的时候
微信群号、QQ 群号每届都会换，写死在页面上很快就会失效。**最快的办法是直接开一个 GitHub Issue**，或者回班级群里问一句「谁在维护郧中 Wiki」。
:::

## 想自己动手改网站？

如果你会一点技术，可以：

1. 在 GitHub 上找到本站仓库
2. 页面底部点「发现错误？帮我们改一改」
3. 直接在线编辑，提交后等审核

## 关于你的内容

- **署名**：默认显示你在表单里填的名字，可以写「某同学」或留空（显示为「匿名同学」）
- **修改**：上线后你随时可以要求修改或删除
- **版权**：内容按 CC BY-NC-SA 4.0 共享，允许转载但需署名、不得商用

::: tip 写得不好也没关系
我们可以帮你改。**最怕的是你觉得「我写的太简单了，不值得发」。** 一句「三食堂二楼靠窗的位置下午有太阳，别坐」对别人就是有用的信息。
:::
