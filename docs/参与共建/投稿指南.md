# 投稿指南

## 最快的方式

**别读这篇，直接用[在线投稿工具](/参与共建/投稿工具)。** 填表、下载、发给我们，完事。

下面这些是给想写得更专业、或者想直接改代码的同学看的。

## 一篇文章的基本结构

```
1. 一句话说清这篇讲什么（开头）
2. 分 2–4 个小节，每节一个主题
3. 具体做法 / 清单 / 表格
4. 注意事项、坑、例外情况
```

不需要文采。Wiki 的价值在**准确**和**具体**，不在好看。

### 好标题 vs 坏标题

| 不好 | 好 |
| --- | --- |
| 关于食堂的一些介绍 | 三食堂二楼：几点人最少、哪几个窗口值得排 |
| 学习经验分享 | 晚自习最后 20 分钟该干什么 |
| 新生必看 | 报到那天从校门到宿舍的完整路线 |
| 郧阳中学简介 | 郧山书院到郧阳中学：四百多年里换了几个名字 |

好标题 = **读者能立刻判断「这是不是我要找的」**。

## 内容标准

### 先问自己一句

**这段话，换到任何一所学校还成立吗？**

如果成立，它就不是这个站要的内容——网上已经有几万篇了。我们要的是**只有郧中人写得出来的部分**：几号楼、几点、找谁、哪一年定的。

这也是为什么站上现在只有很少几篇：写得泛的，已经被全部撤下了。

### 三个「必须」

1. **必须是事实或亲身经验**。不要写「听说」「据说」
2. **必须具体**。「注意时间管理」没用，「晚自习按 40 分钟一块切」有用
3. **必须标明时效**。写清是哪一年的情况

### 三个「不要」

1. **不要写成心灵鸡汤**。读者是来找信息的，不是来被鼓励的
2. **不要写对具体个人的负面评价**
3. **不要复制粘贴别人的文章**

## 格式速查

用在线投稿工具的话，格式会自动生成。手写的话看这里：

```markdown
---
title: 文章标题
order: 1
date: 2026-09-01
reviewedAt: 2026-09-01
category: 校园生活
author:
  - name: 你的名字
description: 一句话摘要，会显示在卡片上
tags:
  - 标签1
  - 标签2
---

# 文章标题

正文从这里开始。

## 小标题用两个井号

- 列表用短横线
- 每行一条

| 表头 | 表头 |
| --- | --- |
| 内容 | 内容 |
```

### frontmatter 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文章标题，会显示在目录和页面顶部 |
| `order` | 否 | 在目录里的排序，数字小的在前 |
| `date` | 是 | 写作日期，格式 `YYYY-MM-DD` |
| `reviewedAt` | 是 | 最后核实日期。超过一年会自动提示「可能过期」 |
| `category` | 是 | 必须和栏目名完全一致 |
| `author` | 否 | 署名，可写多个 |
| `description` | 否 | 一句话摘要 |
| `tags` | 否 | 标签，最多 3 个 |
| `needsReview` | 否 | 写 `true` 会在页面上挂「尚未核实」提示 |
| `draft` | 否 | 写 `true` 则不在列表中显示 |

### 一个中文写作特有的坑

加粗的星号**不要紧跟在中文标点后面**。这是 Markdown 的规则限制，会导致加粗失效、页面上露出两个星号。

```markdown
✗ 错误：**这句话很重要。**后面接着正文
✓ 正确：**这句话很重要**。后面接着正文
```

记不住也没关系：**加粗只包住文字，标点放在星号外面**，永远不会错。

## 图片怎么处理

**不要把图片直接塞进仓库**，会让网站变得很慢。正确做法：

1. 图片单独打包发给 Wiki 小组
2. 或者上传到图床，把链接贴进文章
3. 截图请**裁掉无关部分**，手机截图体积很大

图片文件名用英文或拼音，不要用中文和空格。

## 常见退稿原因

- **事实无法核实**，且找不到人确认
- **包含他人隐私**（电话、成绩、住址）
- **对个人的负面评价**，且无证据
- **内容太笼统**，比如通篇「要努力」「要珍惜时间」
- **涉及版权材料**（教材扫描件、试卷原文）
- **广告性质**（推荐具体商家并附联系方式）

## 写完自己检查一遍

- [ ] 标题能让人一眼知道讲什么
- [ ] 开头三行说清了这篇解决什么问题
- [ ] 至少有 2 个具体可执行的建议
- [ ] 没有「听说」「据说」
- [ ] 没有他人隐私
- [ ] 标了日期
- [ ] 自己读一遍，有没有错别字
