# 参与共建

这个站没有编辑部，没有稿费，也没有 KPI。它存在的原因很简单：**每年都有一批新生，重新踩一遍我们已经踩过的坑。**

你花十分钟写下的东西，可能会让某个素未谋面的学弟少走半年弯路。

## 四种贡献方式，选一个就行

### 方式一：在线投稿（最省事，不需要会任何技术）

打开[在线投稿工具](/参与共建/投稿工具)，把内容填进表单，点「下载」。你会得到一个格式正确的 `.md` 文件，连同图片一起发给 Wiki 小组即可。

**不需要注册、不需要会 Markdown、不需要懂 Git。**

### 方式二：直接发文字给我们

如果你连下载文件都嫌麻烦，可以直接在 [GitHub 上开一个 Issue](https://github.com/friday402-12/yunyang-wiki/issues/new?template=content-issue.yml) 把内容粘进去，格式随便。我们负责整理排版。

不方便用 GitHub 的话，发到班级群里转给 Wiki 小组的同学也行——群号每届会变，所以不在这个页面上写死。

### 方式三：进后台写（推荐给经常投稿的同学）

我们有一个图形化后台，像发朋友圈一样填标题、选栏目、写正文、传图片，不用碰任何文件。

**但要注意：你在后台保存的内容不会立刻上线，会先进入「待审核」状态，等站长点了发布才出现在网站上。**

想开通后台权限，看[编辑团队与权限](/参与共建/编辑团队)这一页。

### 方式四：直接改代码（适合会一点技术的同学）

在任意页面底部点「发现错误？帮我们改一改」，会直接跳到 GitHub 的编辑页面。改完提交，等审核合并即可。

## 什么样的内容值得写

### 特别需要的

- **只有你知道的事**：某栋楼的具体位置、某个办事窗口的作息、某位老师的答疑习惯
- **踩过的坑**：什么事让你后悔、什么说法是骗人的
- **流程类**：怎么办某个手续、怎么申请某个东西，越具体越好
- **经验类**：某个科目怎么学、某次考试怎么复盘有效

### 需要谨慎的

- **对具体老师的评价** —— 只写可核实的事实（如「答疑很耐心」），**不要写人身攻击、不要写未经证实的传闻**。这类内容一律会被驳回
- **未公开的内部信息** —— 学校未公开的文件、成绩排名、他人隐私，不要写
- **教材、试卷、教辅的电子版** —— 涉及版权，不能上传
- **个人联系方式** —— 老师、同学的电话、微信，未经本人同意不收录

::: danger 三条红线
1. **不写他人的隐私**（姓名 + 电话、住址、身份证、成绩）
2. **不写违法和危险内容**（翻墙方法、作弊技巧、违禁品获取）
3. **不造谣、不传谣**（未经证实的消息，宁可不写）
:::

## 投稿之后会发生什么

1. 我们收到你的内容（可能是文件，也可能是一段文字）
2. 一位同学负责校对：检查事实、润色语句、统一格式
3. 如果涉及敏感内容（比如对老师的评价），会和你确认后再处理
4. 上线，页面底部会署你的名字（也可以写「某同学」或匿名）
5. 一年后如果没人更新，页面会自动挂上「内容可能过期」的提示

## 关于署名和版权

- 默认署名，你可以选择真名、昵称或匿名
- 内容采用 **CC BY-NC-SA 4.0** 协议：允许转载，但必须署名、不能商用、且要以相同方式共享
- 你不想要署名，随时可以联系我们去掉

## 我们需要什么样的伙伴

除了写文章，还缺这几种人：

| 角色 | 做什么 | 需要什么 |
| --- | --- | --- |
| 分区负责人 | 盯一个栏目，保证内容不过期 | 有责任心，了解那个领域 |
| 校对 | 改错字、顺语句、查事实 | 语文功底，细心 |
| 技术维护 | 改页面样式、修 bug | 会一点前端 |
| 摄影 | 拍校园照片（教室、食堂、路线） | 有手机就行 |
| 传声筒 | 在班级群、老乡群里转发本站 | 社牛 |

有意向的话，在[投稿工具](/参与共建/投稿工具)里随便留一段话说明就行。

## 这个站的原则

- **不商业化**。没有广告、不卖资料、不接推广
- **不代表学校**。所有内容都是学生视角，与学校官方无关
- **可以被纠正**。我们不一定对，但我们愿意改
- **长期主义**。不追求爆款，只追求三年后还有人用
