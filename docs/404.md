# 这个页面不存在（404）

一般是这几种情况：链接抄错了、文章改了名字，或者我们真的把它删了。

## 从这里继续

- [回到首页](/) —— 从六个栏目里挑一个
- [浏览全部文章](/categories/) —— 按分类找，带摘要和日期
- 用右上角的**搜索**试试关键词，支持中文，比如「食堂」「选科」「报到」

## 如果你确定这个地址应该有内容

那可能是一次误删或改链接。告诉我们，我们尽快补回来。

[报告失效链接](https://github.com/friday402-12/yunyang-wiki/issues/new?template=content-issue.yml&title=%5B%E5%A4%B1%E6%95%88%E9%93%BE%E6%8E%A5%5D) ·
[投稿或纠错](/参与共建/投稿工具)

::: tip 别因为一个 404 就走
更常见的原因是我们自己把链接写错了。你手上有原始链接的话，发给我们，能帮下一个遇到同样问题的人。
:::
