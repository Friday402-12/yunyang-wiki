# 竞赛与强基

::: warning 招生政策每年调整
强基计划、综合评价、专项计划的报名条件与时间每年都会变。**请以教育部阳光高考平台和目标高校当年招生简章为准。**
:::

## 先问自己一个问题

**你是因为喜欢这门学科，还是因为想走捷径？**

如果是后者，建议放弃。竞赛的投入产出比在大多数情况下并不划算：

- 需要大量额外时间，直接影响高考科目
- 只有省一等奖以上才有实际作用
- 天赋和师资的依赖度很高

如果是前者，竞赛会给你远超奖项本身的东西：思维方式、自学能力、抗压能力。

## 五大学科竞赛的基本盘

| 学科 | 特点 | 适合谁 |
| --- | --- | --- |
| 数学 | 门槛最高，含金量最高 | 数学长期稳定在年级前列 |
| 物理 | 需要较强数学基础 | 物理突出、抽象思维强 |
| 化学 | 记忆 + 实验并重 | 化学有兴趣且细心 |
| 生物 | 记忆量大，相对易入门 | 生物突出、肯下功夫 |
| 信息学 | 需要编程基础 | 有编程经验、逻辑强 |

## 时间节点（大致）

- **高一上**：接触、试水。参加学校组织的竞赛培训或自学入门
- **高一下 / 高二上**：参加省级预赛、联赛。这是最关键的一年
- **高二下**：如果拿到省一，可争取省队、参加冬令营
- **高三**：除非已经拿到保送或强基破格资格，一律回归高考

::: danger 一条铁律
**不要让竞赛拖垮高考。** 每年都有人高二全力冲竞赛，结果既没拿到关键奖项，文化课也掉了下来，最后两头空。给自己设一个止损点：如果高二结束还没出成绩，果断回归。
:::

## 强基计划：它到底是什么

强基计划是部分高校（主要是 985）招收基础学科拔尖学生的渠道，专业集中在**数学、物理、化学、生物、力学、基础医学、历史、哲学、古文字学**等基础学科。

### 几个关键事实

1. **不是低分上名校的捷径**。入围靠高考成绩，通常要达到该校统招线附近
2. **专业选择受限**。录取后一般不能转到其他专业
3. **有校考环节**。高考后参加高校组织的笔试、面试、体测
4. **培养方式特殊**。小班制、导师制，但学业压力大，有考核分流机制

### 适合谁

- 对基础学科有真兴趣，愿意读到博士
- 高考成绩稳定在目标高校分数线附近
- 能接受「专业锁定」这个约束

### 不适合谁

- 只想拿个名校文凭
- 对专业方向还没想清楚
- 想学计算机、金融这类应用型专业

## 其他升学渠道

除了裸分高考和强基，还有几条路，值得提前了解：

- **综合评价**（部分高校，看高考 + 校测 + 学业水平考试）
- **高校专项计划 / 地方专项计划**（面向农村和贫困地区学生）
- **国家专项计划**
- **艺术类、体育类**（需专业统考/校考）
- **空军/海军招飞**（有严格的体检和时间节点）
- **公费师范生、优师专项**（有服务期约定）

::: tip 农村户籍的同学务必留意
国家专项、高校专项、地方专项对户籍和学籍有严格要求，且**报名时间很早**（通常高三上学期）。很多符合条件的学生因为不知道而错过。开学就问班主任：我符合专项计划条件吗？
:::
