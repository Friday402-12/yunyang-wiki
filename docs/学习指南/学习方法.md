# 学习方法

## 一条主线：输入 → 加工 → 输出

学习效果差，通常不是输入不够，而是**缺了加工和输出**。

| 环节 | 常见做法 | 有效性 |
| --- | --- | --- |
| 输入 | 上课听讲、看书、看视频 | 低（只是「知道」） |
| 加工 | 整理笔记、画框架、复述 | 中 |
| 输出 | 做题、讲给别人听、默写 | **高** |

「上课都听懂了，一考就错」，原因就在这里：听懂是输入，考试要的是输出。

## 错题本：90% 的人用错了

### 常见的错误用法

- 抄题 + 抄答案 → 变成手抄工厂，浪费时间
- 抄完再也不看 → 只是心理安慰
- 所有错题都记 → 本子太厚，无从复习
- 只记答案不记原因 → 下次照样错

### 正确用法

**只记三类题：**

1. **不会做** 的题（知识漏洞）
2. **会做但错** 的题，且错误原因重复出现
3. **有更好解法** 的题

剩下的（看错一个数字、算错一次加法）不用抄，直接在卷子上标记即可。

**每条只写四行：**

```
题目来源：2026 秋季月考 数学 第 18 题
我的错误：把「至多」看成「至少」
正确思路：先读题圈关键词，再动笔
一句话提醒：概率题的「至多/至少」必须下划线
```

**关键在复习节奏：**

- 每周日花 20 分钟，只看「一句话提醒」那一栏
- 每月末，把已经连续两次做对的题划掉
- 考前只看没划掉的

::: tip 用手机代替错题本
拍照 + 备忘录，比手抄快得多。关键是**建一个能搜索的标签体系**，比如 `#数学#概率#审题`。手机的优势是随时能翻，而本子你大概率不会带在身上。
:::

## 笔记：不要抄板书

### 记什么

- **老师反复强调的**（这是考点信号）
- **老师讲但书上没有的**（补充内容、例题、口诀）
- **你当时没跟上、课后要补的**（画个问号，别停在那里抄）
- **你自己的疑问**

### 不记什么

- 书上原样有的定义
- 完整的板书（老师写得清楚，不如听明白）

### 课后 5 分钟补全

下课后花 5 分钟，把课上打问号的地方补上，或者去问老师。这 5 分钟的收益，比晚上多刷半小时题高。

## 从「听懂」到「会做」的三个动作

### 动作一：合上书，讲一遍

学完一节，合上书，用自己的话讲一遍这个概念。讲不下去的地方，就是你没真懂的地方。

### 动作二：做「最小可验证练习」

不要一上来做难题。先做 3 道最基础的题，确认基本操作没错，再往上加难度。

### 动作三：间隔重复

同一个知识点，在**1 天后、3 天后、7 天后**各回顾一次，比连续学 3 小时有效得多。这就是为什么「考前突击」能过但记不住。

## 各科的一点具体建议

### 数学

- 题型归纳比刷题量重要。同一类题做 5 道并总结规律，胜过盲目做 20 道
- 草稿纸分区写，考场上能省下大量检查时间
- 每天保持手感，哪怕只做 3 道

### 语文

- 作文素材要「攒」不要「背」。建一个素材本，按主题分类
- 古诗文默写是送分题，每天 10 分钟，别丢
- 阅读理解先看题再读文，效率高一倍

### 英语

- 单词是地基，**每天固定量，不能断**
- 阅读靠泛读积累，每天一篇，不求全懂
- 作文背 5 个万能句型，比背 50 篇范文有用

### 物理 / 化学 / 生物

- 物理：先把模型画出来，再列方程
- 化学：方程式和实验现象必须过手写，不能只看
- 生物：课本上的每一句话都可能是考点，精读教材

### 政治 / 历史 / 地理

- 先搭框架（时间线、地域、逻辑链），再填细节
- 大题要练「术语化表达」，口语化答案拿不到分
- 地理要会看图，图看不懂等于不会

## 一个反直觉的建议

**每天留 30 分钟做「无用」的事**：散步、发呆、运动、和同学聊天。

长期高压下，大脑需要恢复时间。把所有时间都填满学习，效率反而下降。这不是鸡汤，是注意力的基本规律。
