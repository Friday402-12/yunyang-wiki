# 分班与考试

::: warning 具体政策请以学校通知为准
分班规则、考试频次属于学校教学管理安排，每年可能调整。本文讲的是**通用规律和应对方法**，具体政策请以年级组通知为准。
:::

## 分班：一次考试不该定义你

### 常见的分班依据

多数高中综合以下几项：

- 中考成绩 / 入学摸底考
- 入学后的分班考试
- 高一上、下学期的期中期末成绩（用于高二重新分班）
- 选科组合（新高考地区，高二会按选科重新编班）

### 关于「进不进重点班」

这是个被过度焦虑化的问题。几个事实：

- **重点班不是保险箱**。重点班的进度更快、竞争更激烈，跟不上会非常痛苦
- **普通班也有大量考上好学校的人**。真正决定结果的是你自己的学习闭环，不是班级标签
- **分班是流动的**。多数学校高二、高三还会重新分班，高一的班级不决定一切

::: tip 如果被分到不满意的班
做三件事：确认分班规则是否公开透明；找班主任聊一次，了解差距在哪；然后把注意力放到下一次能改变分班的考试上。抱怨规则是最没有产出的选择。
:::

## 考试的节奏

高中三年，考试密度大致是：

| 阶段 | 主要考试 | 作用 |
| --- | --- | --- |
| 高一上 | 入学摸底、期中、期末 | 定基线，找差距 |
| 高一下 | 期中、期末、可能的分班考 | 决定高二编班 |
| 高二 | 期中、期末、学业水平考试 | 打基础，定选科 |
| 高三上 | 一轮复习考、月考、联考 | 查漏补缺 |
| 高三下 | 二轮、模考、高考 | 应试状态调整 |

考试密度本身不重要，重要的是**你有没有从每次考试里拿到东西**。

## 考后复盘：比考试本身更重要

大多数人的复盘只有一句话：「这次没考好，下次努力。」这等于没复盘。

### 一个 20 分钟的复盘模板

考完当天或第二天，花 20 分钟，按这四步做：

**第一步：分类失分**

把丢的分分成三类，分别记下分数：

| 类型 | 说明 | 对策 |
| --- | --- | --- |
| **不会** | 知识点没学过或没掌握 | 回归课本，找老师讲 |
| **会但错** | 思路对，算错/写错/看错题 | 专项训练准确率 |
| **没时间** | 会做但没来得及 | 提速，学会取舍 |

**第二步：找出「会但错」的具体原因**

不要写「粗心」。粗心是结果，不是原因。写具体：

- 抄错数字
- 符号看反
- 单位没换
- 题目条件漏读
- 草稿太乱导致自己看错

这些每一条都有对应的解决办法。

**第三步：定一个可执行的动作**

不要写「下次注意」。写：

- 「以后解方程第一步先抄一遍原式」
- 「选择题做完立刻填涂，不留到最后」
- 「草稿纸按题号分区写」

**第四步：把错题归档**

见[错题本怎么用](/学习指南/学习方法)。

## 关于排名

排名是有用的信息，但它只说明**你在这次考试、这份卷子里，处于什么位置**。

- 看排名，更看**排名变化趋势**，单次波动不用太在意
- 别把排名当身份。它是数据，不是评价
- 如果排名持续下滑，先查原因（睡眠？方法？情绪？），别直接加大做题量
