# 学习指南

这一栏不讲「要努力」这种话。努力是默认值。

这里要讲的是更具体的问题：分班考什么范围、月考该怎么复盘、选科什么时候必须定下来、竞赛班怎么进。

::: info 为什么这一栏是空的
「整理错题本」「番茄工作法」这类内容，网上到处都是，写在这里没有意义。

**只有郧中人才知道的部分**——比如哪次月考按什么比例算、选科在高一下第几周截止、竞赛班什么时候选拔——才是这一栏该有的东西。
:::
