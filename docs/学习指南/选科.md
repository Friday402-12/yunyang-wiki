# 选科怎么选

选科是高中三年最重要的一次决策，因为它的影响会一直延续到大学专业和职业方向。但大部分人选科时只用了一个维度：**这次考了多少分**。

::: warning 政策以本省最新文件为准
选科模式（3+1+2 / 3+3）、专业选考要求每年都在微调。**必须以湖北省教育考试院当年发布的选考科目要求为准**，本文只讲决策方法。
:::

## 三个维度，缺一不可

### 维度一：能力（你现在能考多少分）

这是基础，但不是全部。看成绩时要注意：

- 看**排名**而不是分数。不同科目难度不同，绝对分数没有可比性
- 看**趋势**。高一上和高一下的排名变化，比单次成绩更能说明问题
- 看**投入产出比**。同样从 70 分提到 85 分，有的科目花 10 小时，有的花 50 小时

### 维度二：兴趣（你愿意在这上面花时间）

兴趣不能当饭吃，但它决定了你能不能坚持三年。

一个可操作的判断方法：**周末没人逼你的时候，你会不会主动去看这个学科相关的东西？** 会，说明是真兴趣；只是「不讨厌」，那不算。

### 维度三：专业覆盖（你想报的专业要不要求）

这是最容易被忽略、后果最严重的一条。

- 想学医 → 几乎必须选**化学 + 生物**
- 想学工科（计算机、电子、机械）→ 通常要求**物理 + 化学**
- 想学法学、汉语言 → 多数不限，但部分院校有要求
- 想考军警校 → 有明确的科目要求，务必查清

::: danger 别用「哪个容易得分」作为主要依据
每年都有人为了避开物理选历史，结果发现能报的专业大幅缩水，最后不得不复读或接受调剂。**先定专业方向，再定科目，最后看分数。**
:::

## 一张决策表

把候选组合填进去，逐项打分（1–5 分），加权求和：

| 组合 | 当前排名(×3) | 提升空间(×2) | 兴趣(×2) | 专业覆盖(×4) | 总分 |
| --- | --- | --- | --- | --- | --- |
| 物理+化学+生物 | | | | | |
| 物理+化学+地理 | | | | | |
| 历史+政治+地理 | | | | | |

权重是我的建议，你可以按自己的情况调整。但**专业覆盖的权重不该低于 3**。

## 四个常见误区

### 误区一：「我物理不好，所以选历史」

物理不好可能是方法问题，不是能力问题。而且历史拿高分同样难——它需要大量的记忆和论述能力。**换科目不等于换难度，只等于换了一种难。**

### 误区二：「跟着好朋友选一样的」

分科之后你们大概率不在一个班，而且三年后各奔东西。为友谊选科，代价太大。

### 误区三：「听说这个组合赋分高」

赋分高低取决于当年选这个组合的人的水平分布，你无法预测。而且**赋分高的组合往往竞争者也强**。

### 误区四：「爸妈说学医好」

家长的建议要听，但最终是你要读四年、工作几十年。如果实在冲突，可以请班主任或生涯规划老师一起谈一次。

## 决策流程（建议按顺序走）

1. **列出 3–5 个你想报的专业方向**（不知道就写「大概想学理工 / 文史 / 医学 / 商科」）
2. **查这些专业在本省的选考要求**（省考试院官网 + 目标高校招生网）
3. **剔除掉不符合要求的组合**
4. **在剩下的组合里，按能力和兴趣排序**
5. **找两个高年级学长学姐聊一次**，问他们「选了之后后悔吗，为什么」
6. **定下来，别反复改**。改科的沉没成本极高

## 选了之后

- 选科不是终点，**高二一年才是真正拉开差距的时候**
- 如果发现确实选错了，高二是最后的调整窗口，尽早和班主任、家长沟通
- 弱势科目不要放弃，学考要过，而且部分高校综合评价会看全科
